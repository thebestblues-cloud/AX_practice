원인(인쇄 로트·제본·물류 파손·전표 기재 관행)은 데이터로 단정 불가 — 로트·검품 기록 대조 대상

공급률 — 조용히 깎이는 마진

공급률 = Σ출고액 ÷ Σ(출고부수 × 정가) · 하락 판정: 연도 평균 차 −1.0%p 이하 · 침식액 = 최근 12개월 정가 출고액 × 하락폭

ⓐ 연도 평균 차(본문 수치) · ⓑ 첫 달·마지막 달 차를 월수로 나눠 연율화. 하락 원인(계약 개정·프로모션 분담·협상)은 데이터에 없음 — 확인 필요

거래처 분류

반품률·공급률·출고 규모·개정판 직전 물량 비중·파본 비중 5가지 특성이 비슷한 거래처끼리 자동으로 묶음

반품률 × 공급률

원 크기 = 출고부수 · 색 = 분류

공헌이익과 손익분기 반품률

공헌이익 = 실판매 매출 − (출고분 제작원가 − 재판매 가능 반품 원가) − 반품 × 왕복 물류비

거래처별 공헌이익

공헌이익반품으로 줄어든 공헌이익(막대 끝 = 반품이 없었을 때)

현재 반품률 → 손익분기 반품률

현재 누적 반품률손익분기

손익분기 r* = (p − c) ÷ (p − c + L + d·c) · p 평균 공급단가, c 평균 제작원가, L 물류비, d 반품 중 재판매 불가(개정판교체·파본) 비중. 인세·창고·금융비용 미반영 → 실제 손익분기는 더 낮음. 물류비 조정은 이 화면에서만 적용(저장되지 않음)
